# 🎹 深夜鼓房 Midnight Drum Room

沉浸式专注自习室，集成雨滴效果、Live2D 角色、多场景切换和番茄钟功能。

## ✨ 功能特性

- **🌧️ 雨滴效果** — WebGL 渲染的条状雨丝滑落，带折射扭曲效果，还原 Wallpaper Engine 壁纸质感
- **🎨 多场景切换** — 4 个不同风格的专注场景（雨夜、森林、星空、海滨），各有独立背景和氛围音
- **🎵 背景音乐** — 支持多曲目播放，可手动切换
- **📝 今日目标** — 设定每日目标，完成后在右上角留档展示（保留最近 5 条）
- **🍅 番茄钟** — 25 分钟专注计时器
- **👧 Live2D 角色** — 可选显示的互动角色
- **🔊 氛围音控制** — 独立调节雨声、虫鸣等环境音
- **🌫️ 背景模糊** — 实时调节背景模糊度

## 🚀 使用方式

直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖。

### 进入界面
1. 打开页面 → 进入界面（独立背景）
2. 点击 **"进入自习室"** → 选择场景配置
3. 选择场景（1-4）、音乐类型
4. 点击 **"开始专注"** 进入专注模式

### 控件说明
| 控件 | 位置 | 功能 |
|------|------|------|
| 场景切换 | 右上角 | 切换 4 个专注场景 |
| 音乐控制 | 左下角 | 切换/暂停音乐曲目 |
| 氛围调节 | 左下角 | 雨声/环境音量滑条 |
| 背景模糊 | 右上角 | 调节背景虚化程度 |
| 清屏模式 | 右上角 | 隐藏所有 UI 元素 |
| 今日目标 | 右上角 | 设定并展示今日目标 |

## 🛠️ 技术实现

- **雨滴效果**: 纯 WebGL 着色器实现，包含条状雨丝生成、背景折射扭曲、模糊效果
- **场景切换**: CSS 过渡动画 + JavaScript 动态加载背景/音频
- **Live2D**: Cubism 5 运行时，Canvas 渲染
- **音频**: Web Audio API，支持多轨道混合
